# Historical Form 13F baseline

This offline importer is intentionally scoped to the SEC prepared June–August 2026 submission archive. It makes no network requests. Download through the official public link at https://www.sec.gov/data-research/sec-markets-data/form-13f-data-sets and retain the original ZIP plus browser receipt privately.

Run `python3 backend/sec_13f_data.py --root PRIVATE_SOURCE_DIRECTORY --out NEW_PRIVATE_OUTPUT_DIRECTORY`. Output must be outside this checkout in a trusted private parent. The directory is owner-only and the SQLite file is mode 0600. It contains manager addresses, phone numbers and signatures; never commit the ZIP or SQLite database. Only the allowlisted aggregate summary is intended for publication. This utility refusing overwrite is not immutable storage or independent authenticity verification.

Exact known headers, bounded ZIP inventory, row widths, submission identities/dates, accession joins, required singleton tables and matching cover/submission report periods are checked. All seven tables preserve text verbatim, including reporting period, amendment/replacement context, confidential omissions, options, share/principal type, voting/discretion and other-manager relationships. No amendment consolidation or issuer security mapping is attempted. A form/cover amendment mismatch is preserved in a validation-gap table, never silently corrected. Duplicate accession-level singleton rows fail closed. SQLite FULL synchronous commits and reopen counts plus quick_check precede completion output; failed output remains INCOMPLETE.

The real batch contains 11,852 submissions, 10,807 reporting-manager CIKs and 3,830,274 as-filed holding rows. Reporting-manager CIKs are not held-company issuer CIKs and must not increase the separate issuer-coverage count. Filing dates are June 1–August 31, 2026, but reported periods run September 30, 2001–June 30, 2026. These are not current positions or transactions. There is one form/cover amendment mismatch. Preserve all rows, including historical/amended reports.

Bundled SEC README says VALUE is rounded dollars for filings starting January 3, 2023; previously thousands. The importer preserves source text and does not multiply or compute portfolio totals. Confidential holdings may be omitted. CUSIPs are source strings, not authenticated ticker mappings. Raw holdings cannot satisfy present execution prices, auction, halt or corporate-action gates. No orders or historical trading decisions are generated.

The browser exposes neither exact download clock nor HTTP status. Those remain null; local verification time and SHA256 attest only to retained bytes at verification, not first public availability. Source receipt URL and fields are strictly allowlisted. The public manifest contains no individual names, phone numbers, addresses, signatures or holding values. The existing paper ledger and held research reports are unchanged.
