## Reusable but bounded extraction

`backend/issuer_revenue_comparison.py` recognizes one narrow **whole-paragraph** grammatical structure. It does not combine figures from separate paragraphs or infer missing dates. Explicitly prefixed denials, quotations, partial matches, unsupported wording and nonmatching numeric formatting are not accepted. Multiple supported paragraphs are marked ambiguous. It retains raw original paragraph offsets/hash privately. The generic parser itself does not verify an issuer assertion or accounting comparability.

The IEH card is separately restricted to the reviewed exact source SHA, accession/CIK, exhibit filename, date pair and numeric values. It validates ZIP bounds/member uniqueness, exact manifest/filing bytes, receipt identity/order/unknown-publication state, and SEC header identity/dates. It performs no network calls. A fixed reviewed source cannot be substituted with an arbitrary issuer paragraph.

Arithmetic uses exact rational percentages and controlled decimal rounding, independent of the caller's decimal precision. The reported 51% remains distinct from computed 51.18%; the exact fraction is preserved. A positive baseline is required for this supported comparison, without implying a generic growth-screen threshold.

The private output is created with INCOMPLETE first, evidence and finding next, COMPLETE hashes last (0700 directory/0600 files). Public `web/company-findings/ieh-reported-revenue.json` excludes the paragraph text, contacts, addresses and commentary. Existing VitaSpring records, held research reports, paper ledger and schedules remain untouched. No execution or training gate is enabled. UI integration is a separate reviewed release.
