# Retained source to prepared-table correspondence

One independently audited primary filing package and its previously audited Q2 prepared-data SQLite archive yield 14 numerically equal candidate correspondences. These correspond to 17 inline occurrences; the three repeated source-local pairs are not counted twice. Twelve dimensional/scenario groups remain unassessed. All 26 groups have an explicit disposition. No source requests were made.

The utility re-extracts the primary archive, groups exact source-local references, and verifies the original private manifest hash and its ZIP/member hashes, source URL, accession, issuer and reported period against the prepared submission. It verifies the prepared ZIP and SQLite hashes before and after use and opens SQLite read-only. Prior independent ingestion audits establish the database-to-ZIP derivation; hash agreement alone does not. The local manifest is retained observation evidence, not independent authentication or proof of a historical publication clock.

Candidate filters require standard taxonomy version, explicit source units, unique taxonomy definition, a presentation entry, endpoint, empty prepared segments/coreg and an available finite value with no qualifying prepared footnote. Duplicate candidate prepared rows are ambiguous even if numerically equal. A source duration starting on the first and ending on the last day of 3, 6, 9 or 12 calendar months supplies only a candidate qtrs filter. The prepared table lacks an exact start date; the code does not assert duration equivalence or fiscal-calendar comparability. Other spans, including 52/53-week alternatives, remain unassessed. Source EPS requires an explicit USD/shares unit and a prepared perShare datatype plus USD field, not a guessed unit ID. All source contexts and raw rows are retained privately.

Exact Decimal equality does not imply identical accounting meaning, comparable operations, first-public availability or predictive eligibility. Differences would be labeled different reported values, not corrections or restatements. This is not growth, an event qualification, a security-level price join, a training example or model performance. Prepared accepted/filed timestamps remain as-filed metadata, never authenticated decision clocks.

## Use and tests

`backend/source_prepared_correspondence.py` requires the original archive/member paths and expected hashes, prepared database and original ZIP with expected hashes, original identity manifest with expected hash, and a new output directory under a trusted private parent outside this checkout. Use `--help` for exact arguments. Source and prepared values, submission details and row IDs remain in the private candidate file; only aggregate counts and hashes are public. The existing INCOMPLETE/COMPLETE hash protocol applies, and overwrite refusal is not immutability. The tool detects its own checkout, not every possible public directory.

Run `python3 -m unittest discover -s backend -q`. Synthetic cases test issuer mismatch, ambiguous/invalid prepared values, dimensional exclusions, unsupported duration/unit/taxonomy, absent presentation, footnotes and numeric differences. No approved UI, held reports, ledger, existing collectors or execution controls change.
