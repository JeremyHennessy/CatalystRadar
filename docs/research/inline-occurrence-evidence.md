# Source-local repeated occurrence inventory

The retained filing contains 29 target inline occurrences. Grouping by the exact raw member hash, concept namespace/name, contextRef and unitRef produces 26 source-local groups. Three groups contain two occurrences each. All three report numerically equal interpreted values and equal declared decimals attribute. All six occurrences remain retained, including their individual fact IDs, raw text and context evidence. Twelve dimensional/scenario occurrences also remain preserved. The aggregate is not a count of independent economic facts, examples or training rows.

`backend/inline_occurrence_evidence.py` re-extracts the hash-pinned source through the reviewed context and numeric tools. It rejects duplicate occurrence identities and conflicting resolutions of a shared source-local reference. It compares decimal strings exactly without floating point or context-limited arithmetic. Unsupported numerical interpretations remain unavailable, never zero. Different values are called different reported values, not restatements or errors. Declared-decimals differences are reported separately, not used for rounding or tolerance.

This is intentionally not canonical XBRL fact equivalence or general deduplication: two different context IDs or unit IDs never merge here, even if their content seems equivalent. The source-local key does not establish cross-filing comparability, accounting meaning, historical availability, authenticity, security identity or outcome labels. No fact is removed or admitted to training. The earlier numerical evidence remains unchanged.

The private output retains every occurrence; the public dated JSON contains only aggregate counts and source hashes. Run with the same `--archive`, `--archive-sha256`, `--member`, `--member-sha256`, `--output-directory` arguments as the numerical evidence tool. A new directory under a trusted private parent outside this checkout is required. The shared INCOMPLETE/COMPLETE hash protocol applies. Overwrite refusal is not immutable storage; other publication checkouts are not detected. No provider calls, UI changes, held-report updates, execution activation or prepared-table joins occur.

Synthetic tests cover shared occurrences, different numbers, unavailable conversion, changed identifiers/namespaces/member hashes, conflicting reference resolutions, duplicate IDs and long-number comparison under low Decimal precision. Run `python3 -m unittest discover -s backend -q`.
